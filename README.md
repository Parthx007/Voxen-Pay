# Voxen-Pay
Voxen Pay — AI-Powered Finance Assistant 

Voxen Pay is a modern AI-based finance web application designed to simplify digital payments, personal finance management, and smart money tracking through an interactive and user-friendly interface.

The application combines fintech features with AI-powered assistance to provide users with a smarter financial experience. Users can manage wallet transactions, track expenses, monitor savings goals, explore financial insights, and interact with an AI advisor for personalized financial guidance.

✨ Key Features
🔐 Secure Login & Wallet Interface
💳 Smart Digital Wallet System
🎤 Voice-Based Payment Interface
🤖 AI Financial Advisor Chatbot
📊 Expense Tracking & Analytics
🎯 Goal-Based Savings Tracker
📰 Finance Knowledge Feed
📱 Fully Responsive Modern UI
🌐 Multi-language Support (English & Hindi)

🛠️ Technologies Used
HTML5
CSS3
JavaScript
OpenAI API (AI Chatbot Integration)

🚀 Project Vision
The goal of Voxen Pay is to create an AI-driven personal finance ecosystem that makes financial management more accessible, interactive, and intelligent for everyday users.
